# Xmas Daily Privacy Policy

Public static privacy-policy page for the Xmas Daily Android app.

Live target URL:
`https://minhmdl48.github.io/xmas-daily-privacy/`

## GitHub Pages

Enable **Settings → Pages → Deploy from a branch → main → /(root)**.

For a custom domain, add it under **Settings → Pages → Custom domain**, configure the DNS records at the domain provider, verify the domain, and enable HTTPS.

Before submitting to Google Play, confirm the page is public without login/geofencing and keep its content aligned with the Play Console Data Safety form and the app’s AdMob/Pirago/UMP configuration.
